El proyecto

Automatizar con criterio.

Un asistente puede ahorrar tiempo, pero también debe reconocer sus límites. BeautyFlow separa la interpretación del mensaje de las decisiones del negocio.

01

Entiende en tres idiomas

Extrae intención, servicio, fecha y datos de reserva desde mensajes en español, inglés o alemán.

02

Reglas fuera del modelo

El código calcula fechas, consulta los datos del negocio y decide el siguiente paso; el modelo no confirma citas.

03

Deriva lo delicado

Alergias, molestias, reclamaciones y solicitudes no cubiertas se envían a revisión humana.

Diseño del sistema

Tres capas. Un límite claro.

El modelo estructura el mensaje. Python valida y aplica las reglas. Una persona se ocupa de excepciones y casos sensibles.

A

Interpretación

Gemini devuelve campos estructurados; una respuesta mal formada no sigue como si fuera fiable.

B

Flujo determinista

Python resuelve fechas, aplica una lista de seguridad y calcula una puntuación interna.

C

Respuestas con límites

Las respuestas se apoyan en una base de conocimiento sintética. Si faltan datos, el sistema no inventa.

Resultado de ejemplo

Falta consultar la agenda

Se reconoce el servicio y la fecha solicitada. El equipo debe comprobar la disponibilidad antes de responder.

action: check_calendar · service: classic_facial · date: Friday

Ejemplos ilustrativos; no equivalen a una reserva ni a una respuesta en tiempo real.

Estado del prototipo

Una base para seguir construyendo.

Incluye lógica de flujo y pruebas offline. No conecta con un calendario, CRM ni interfaz de cliente.
